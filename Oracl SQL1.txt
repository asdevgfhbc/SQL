Oracle SQL vs Normal SQL
Normal SQL (Standard)  →  හැම database එකකම වැඩ කරනවා
Oracle SQL  →  Oracle database ලා extra features + functions තියෙනවා
Oracle = world's most powerful databases වලින් එකක්.
 Banks, hospitals, government systems ගොඩාක් Oracle use කරනවා.

Database එකකට කතා කරන්නට use කරන language එකක්. ඔයා Sinhala 
ලා කතා කරනවා වගේ, computer ලා database එකට කතා කරන්නේ SQL ලා.
